# ♟️ Jogo de Xadrez em Python

Projeto de estudos em Python desenvolvendo um jogo de xadrez.

 🎮 Comandos

- ESC → Sair do jogo
- R → Girar tabuleiro
- N → Reiniciar partida

 ♟️ Funcionalidades

✅ Movimento das peças  
✅ Captura de peças  
✅ Tabuleiro gráfico  
✅ Peças em imagem  
✅ Girar tabuleiro  
✅ Reiniciar partida  

🔥 Mecânicas Avançadas

- ♟️ Roque
- ♟️ En Passant
- ♟️ Promoção de Peão
- ♟️ Xeque
- ♟️ Xeque-Mate
- ♟️ Empate

🚀 Tecnologias utilizadas

- Python
- Pygame
- GitHub

▶️ Executar o jogo

bash
python xadrez.py
